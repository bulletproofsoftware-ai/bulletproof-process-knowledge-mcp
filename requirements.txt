# Direct dependencies, pinned for reproducible builds.
#
# Previously these were unpinned `>=` floors with no upper bound, so every
# `pip install` resolved a different, unaudited dependency tree. That made
# vulnerability scanning meaningless: the Snyk dashboard and a fresh local
# resolution reported different findings because they were different software.
#
# Embeddings use fastembed (ONNX runtime) rather than sentence-transformers.
# sentence-transformers pulls torch + transformers, which carried 13 findings
# (8 HIGH / 5 MEDIUM) with fixedIn: NONE — inherent pickle/model-loading risks
# present in the newest releases. fastembed produces numerically identical
# vectors for the same model (cosine 1.00000000, max|delta| 1.3e-07), so
# existing Qdrant collections remain compatible with no re-indexing.
#
# Transitive dependencies are pinned in requirements.lock.txt.
# For a byte-identical environment, install from the lockfile instead:
#     pip install -r requirements.lock.txt
#
# To upgrade: change a pin here, reinstall, then regenerate the lockfile with
#     pip freeze --exclude-editable > requirements.lock.txt
